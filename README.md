# YarnVision: Automated Yarn Quality & Defect Detection System

YarnVision is an optical monitoring and analysis web platform designed for yarn spinning mills and quality control laboratories.

## Features
- Real-Time Telemetry: Live monitoring of yarn diameter profiles, speed, and tested length.
- Optical Defect Identification: Real-time detection for Neps (+200%), Thick Places (+50%), and Thin Places (-50%).
- Quality Grading & Export: Automatic calculation of CV% and generation of downloadable PDF/CSV reports.
